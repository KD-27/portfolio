\Needspace{8\baselineskip}
\cventry{\textbf{Lazy Coulomb Planner, a reactive path planner based on electrostatic repulsion}}{2026}
\cvsub{Independent project \quad|\quad \href{https://github.com/KD-27/Lazy-Coulomb-Planner/tree/humble}{github.com/KD-27/Lazy-Coulomb-Planner (humble branch)}}
\begin{cvlist}
  \item Developed a planner that starts with a straight-line path and adds
        repulsive waypoints only at obstacle intersections instead of
        evaluating a continuous potential field.
  \item Implemented perpendicular escape motion and waypoint locking to reduce
        oscillation and local-minimum trapping.
  \item Built the planner as a ROS~2 Nav2 plugin and tested it on a 1.8\,m-tall
        mobile robot. Documented a qualitative comparison with APF, RRT, A*, VFH
        and Bug algorithms, with limitations in narrow passages, concave
        obstacles and path optimality.
\end{cvlist}
